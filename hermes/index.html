Hermes personal Google integration

A privately operated personal-assistant integration for the account owner's own use. This is not a public sign-up service.

What it does

This integration connects Rohan Bansal's personal Hermes Agent installation to Google services so the assistant can carry out authorized productivity tasks: search and summarize Gmail messages, draft or send requested email, read and manage calendars, find and work with Drive files, edit Docs and Sheets, and look up contacts.

How access works

The account owner grants access through Google's OAuth consent flow. Access is used for owner-requested tasks and explicitly configured automations, not to provide access to unrelated users. The scope of an individual task may be narrower than the permissions granted to the integration.

About these pages

These public pages describe this personal integration only. They do not expose a mailbox, calendar, files, assistant console, or a sign-in service. Hermes Agent is developed by Nous Research; this personal deployment is operated independently and these are not Nous Research's corporate policies.
